# 置きかえの例

左の言葉を見つけたら、右を考えます。
画面の表示名やコマンド名になっているときは、置きかえません。

## よく出る言葉

| かたい言い方 | やわらかい言い方 |
| --- | --- |
| 動作環境、必要要件 | いるもの |
| インストールする | 入れる |
| 起動する | 動かす、開く |
| 終了する、停止する | 止める、閉じる |
| 実行する | 動かす（コマンドなら「実行する」のままでもよい） |
| 権限を付与する | 許可する |
| 送信する、受信する | 送る、受け取る |
| 取得する | 読む、もらう、とってくる |
| 削除する | 消す |
| 表示する | 出す、見せる |
| 判定する | 見分ける、決める |
| 検出する | 見つける |
| 変換する | 変える |
| 保持する | 残しておく |
| 推奨する | 〜がおすすめです、〜してください |
| 必須 | 必ずいる |
| 任意 | なくてもよい |
| 上限、最大値 | 最大 |
| 閾値 | 基準の数 |
| デフォルト | はじめの値 |
| オプション、フラグ | スイッチ、追加の指定 |
| 引数 | 渡すもの |
| 依存パッケージ | 使う部品 |
| APIキー、トークン | 鍵 |
| 実装 | 作り、中身 |
| 仕様 | 決まり、動き方 |
| 挙動 | 動き |
| 対象外 | 使えません、入っていません |
| 不具合、障害 | うまく動かないこと |
| エラーが発生する | 失敗する、エラーが出る |
| 留意する | 気をつける |
| 確認する | たしかめる、見る |

## 文の中のつなぎ

| かたい言い方 | やわらかい言い方 |
| --- | --- |
| 本〜、当該〜 | この〜、その〜 |
| 及び | と |
| 又は | か、または |
| 等 | など |
| 下記 | 次 |
| 上記 | ここまでの、前の |
| 〜に関して | 〜について |
| 〜の上で | 〜してから |
| 〜の際 | 〜とき |
| 事前に | 先に、前に |
| なお、 | （文を分けて、何もつけない） |

## ひらく語

こと、とき、ところ、もの、できる、ください、ように、など、いる、ある、ほか、あいだ、まだ、すでに、もともと、わかる、たしかめる
